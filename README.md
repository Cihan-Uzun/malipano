# MaliPano

**Muhasebe ofisin icin tek panel**

Turk SMMM ofisleri icin cok kiracili SaaS paneli.

## Kurulum

1. `cp .env.example .env`
2. `npm install`
3. `npx prisma db push`
4. `npm run seed`
5. `npm run dev`
